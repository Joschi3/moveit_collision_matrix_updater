# MoveIt Collision Matrix Updater
![lint-build-test](https://github.com/Joschi3/moveit_collision_matrix_updater/actions/workflows/lint_build_test.yaml/badge.svg)

This repository provides tooling around maintaining a correct **self-collision matrix** in a robot’s SRDF:

1. A **C++ command-line tool** that regenerates the collision matrix using the same algorithm as the MoveIt Setup Assistant.
2. A **Python checker** that runs the generator in a temporary environment, compares the results, and optionally updates the existing SRDF in-place while preserving comments and formatting.
3. A **pre-commit hook** that automatically verifies that the SRDF is up-to-date before commits.

This enables fully automated, reproducible MoveIt configuration pipelines—without ever opening the GUI Setup Assistant again.

---

# 1. C++ Collision Matrix Generator

The binary:

```
ros2 run moveit_collision_matrix_updater moveit_collision_matrix_updater
```

regenerates the `<disable_collisions>` block inside an SRDF using MoveIt’s original `DefaultCollisions` algorithm.

It is designed for:

* headless usage
* scripting
* large CI pipelines
* multi-robot repositories

## Features

* Computes the collision matrix using MoveIt’s sampling logic
* Reads URDF and SRDF directly from disk
* Supports an optional **output SRDF path**
* Preserves special octomap collision entries (`&lt;octomap&gt;`)
* Works in headless environments (Docker, CI, build servers)

---

## Usage

```bash
ros2 run moveit_collision_matrix_updater moveit_collision_matrix_updater \
    <urdf_file> <srdf_file> [num_trials] [min_fraction] [output_srdf_file]
```

### Arguments

| Argument           | Description                                              | Default       |
| ------------------ | -------------------------------------------------------- | ------------- |
| `urdf_file`        | Path to the URDF file                                    | —             |
| `srdf_file`        | Path to the input SRDF file                              | —             |
| `num_trials`       | Number of random samples used for collision detection    | `50000`       |
| `min_fraction`     | Minimum fraction of collisions before disabling the pair | `0.95`        |
| `output_srdf_file` | Output path (if omitted, SRDF is overwritten)            | same as input |

### Example

```bash
ros2 run moveit_collision_matrix_updater moveit_collision_matrix_updater \
    athena.urdf athena.srdf 50000 0.95 athena_updated.srdf
```

# 2. Python SRDF Collision Matrix Checker

`scripts/check_collision_matrix.py` ensures that a MoveIt SRDF collision matrix matches the one that would be generated by the C++ updater.

It is intended for pre-commit hooks and CI sanity checks.

## Features

* Resolves URDF/Xacro and SRDF via `ament_index_python`
* Accepts additional `--xacro-arg` parameters
* Generates temporary URDF if input is `.xacro`
* Runs the C++ collision updater internally
* Compares `<disable_collisions>` entries between original and regenerated SRDF
* Works non-destructively by default
* Supports `--fix` and `--yes` to patch the SRDF in-place
* Preserves formatting, comments, order of all other SRDF elements
* Alphabetically sorts the regenerated collision matrix block
* Preserves octomap entries (`&lt;octomap&gt;`)

---

## Usage

```bash
python3 scripts/check_collision_matrix.py \
  --package-urdf my_robot_description \
  --urdf-path urdf/robot.urdf.xacro \
  --package-srdf my_robot_moveit_config \
  --srdf-path config/robot.srdf \
  --xacro-arg robot_variant:=athena \
  --fix \
  -y
```

### Flags

| Flag           | Meaning                                                  |
| -------------- | -------------------------------------------------------- |
| `--fix`        | Update only the `<disable_collisions>` lines of the SRDF |
| `--yes` / `-y` | Non-interactive mode                                     |
| `--xacro-arg`  | Extra xacro arguments, repeatable                        |



# 4. Pre-Commit Hook

A `.pre-commit-hooks.yaml` entry is provided that allows to run the `check_collision_matrix.py` script on every commit.

## Example Usage in a moveit_config pkg
Add a `.pre-commit-config.yaml` file like this to your repository. Make sure the `moveit_collision_matrix_updater` is build or installed and run it via `pre-commit run -a` or to run in on every commit use `pre-commit install`.
```yaml
repos:
  - repo: https://github.com/Joschi3/moveit_collision_matrix_updater
    rev: v0.1.0
    hooks:
      - id: check-moveit-collision-matrix
        always_run: true
        pass_filenames: false
        args:
          - --package-urdf
          - athena_description
          - --urdf-path
          - urdf/athena.urdf.xacro
          - --package-srdf
          - athena_moveit_config
          - --srdf-path
          - config/athena.srdf
          - --xacro-arg
          - robot_name:=athena
```
